# 校园伙伴语音扩充

本次新增 20 组固定台词，每组包含中文、英语、日语、俄语，共 80 条新录音。与原来的 14 组、56 条录音合并后，语音库共 34 组、136 条。

沿用已有用户提供的音色权重和参考音频进行本地推理。此次未新增真人训练素材，未重新微调模型权重。中英日使用 GPT-SoVITS v2；俄语使用 XTTS-v2 与已有音色条件。

首页新增五个时段的问候和办事提示；论坛新增分享、迎新、友好交流、活动发现；跑腿新增取件隐私、核对任务、致谢、安全提醒；导诊新增信息整理、候诊提示、关怀；预约新增自习、运动、核对预约。

首页仅轮换当前时段问候和通用计划台词。其他模块进入时随机选取对应场景台词，“换一句”遍历本模块语音。办事引导状态下也可以切换问候，办事入口保持可用。

`expansion-verification.json` 记录新增音频时长、采样率、音量、削波比例及 SHA-256。原 56 条录音保留；检查覆盖文件完整性与信号指标，不代表四种语言的人工发音验收。

这些录音用于固定问候。实时 AI 回复仍使用设备语音朗读，与固定音色录音分开。
